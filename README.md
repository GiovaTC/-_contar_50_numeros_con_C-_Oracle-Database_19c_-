Contar 50 números con C# y Oracle Database 19c:
Aplicación de consola desarrollada en C# para Visual Studio 2026 (.NET 10) que genera los números del 1 al 50, los almacena en Oracle Database 19c, consulta los datos guardados y los imprime en consola.

Características
- Conexión a Oracle 19c mediante Oracle.ManagedDataAccess.Core.
- Generación de los números del 1 al 50.
- Inserción de los 50 números dentro de una transacción.
- Consulta de los números guardados en la ejecución actual.
- Impresión de los números y del total consultado.
- Identificador único (LOTE_ID) para distinguir cada ejecución.

Requisitos
- Visual Studio 2026.
- .NET 10 SDK.
- Oracle Database 19c.
- SQL Developer u otra herramienta para ejecutar sentencias SQL.
- Usuario Oracle con permisos para crear y consultar la tabla.

1. Crear la tabla en Oracle 19c
Conéctate a Oracle desde SQL Developer y ejecuta el siguiente script. Si utilizas un usuario distinto de SYSTEM,
crea la tabla con ese usuario .

CREATE TABLE NUMEROS_CONTADOS (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    LOTE_ID VARCHAR2(36) NOT NULL,
    VALOR NUMBER NOT NULL,
    FECHA_REGISTRO TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
);

CREATE INDEX IDX_NUMEROS_LOTE
    ON NUMEROS_CONTADOS (LOTE_ID);

4. Código completo de Program.cs
Configuración: sustituye TU_CLAVE por la contraseña de tu usuario Oracle. Ajusta localhost:1521/orcl si tu host,
puerto o nombre de servicio son diferentes. Es preferible usar un usuario de aplicación con permisos limitados en lugar de SYSTEM.

using System;
using Oracle.ManagedDataAccess.Client;

namespace Contar50NumerosOracle
{
    internal class Program
    {
        static void Main(string[] args)
        {
            // Configuración de conexión a Oracle 19c.
            string cadenaConexion =
                "User Id=SYSTEM;" +
                "Password=TU_CLAVE;" +
                "Data Source=localhost:1521/orcl;";

            // Identificador único para esta ejecución.
            string loteId = Guid.NewGuid().ToString();

            int totalProcesado = 0;

            Console.WriteLine("==================================");
            Console.WriteLine("   CONTADOR DE 50 NUMEROS");
            Console.WriteLine("   C# + ORACLE DATABASE 19c");
            Console.WriteLine("==================================");
            Console.WriteLine();

            try
            {
                using (OracleConnection conexion =
                       new OracleConnection(cadenaConexion))
                {
                    conexion.Open();

                    Console.WriteLine("Conexion a Oracle exitosa.");
                    Console.WriteLine();

                    // Insertar los 50 números en una transacción.
                    using (OracleTransaction transaccion =
                           conexion.BeginTransaction())
                    {
                        try
                        {
                            string sqlInsertar = @"
                                INSERT INTO NUMEROS_CONTADOS
                                    (LOTE_ID, VALOR)
                                VALUES
                                    (:loteId, :valor)";

                            using (OracleCommand comando =
                                   new OracleCommand(
                                       sqlInsertar,
                                       conexion))
                            {
                                comando.Transaction = transaccion;

                                comando.Parameters.Add(
                                    "loteId",
                                    OracleDbType.Varchar2,
                                    36).Value = loteId;

                                comando.Parameters.Add(
                                    "valor",
                                    OracleDbType.Int32);

                                for (int numero = 1;
                                     numero <= 50;
                                     numero++)
                                {
                                    comando.Parameters["valor"].Value =
                                        numero;

                                    comando.ExecuteNonQuery();
                                }
                            }

                            transaccion.Commit();
                        }
                        catch
                        {
                            transaccion.Rollback();
                            throw;
                        }
                    }

                    Console.WriteLine(
                        "Numeros guardados correctamente en Oracle.");
                    Console.WriteLine();

                    // Consultar únicamente los números de esta ejecución.
                    string sqlConsultar = @"
                        SELECT VALOR
                        FROM NUMEROS_CONTADOS
                        WHERE LOTE_ID = :loteId
                        ORDER BY VALOR";

                    using (OracleCommand comando =
                           new OracleCommand(sqlConsultar, conexion))
                    {
                        comando.Parameters.Add(
                            "loteId",
                            OracleDbType.Varchar2,
                            36).Value = loteId;

                        using (OracleDataReader lector =
                               comando.ExecuteReader())
                        {
                            Console.WriteLine(
                                "Numeros consultados desde Oracle:");
                            Console.WriteLine();

                            while (lector.Read())
                            {
                                int numero = lector.GetInt32(0);

                                Console.WriteLine($"Numero: {numero:D2}");
                                totalProcesado++;
                            }
                        }
                    }
                }

                Console.WriteLine();
                Console.WriteLine("==================================");
                Console.WriteLine(
                    $"TOTAL DE NUMEROS: {totalProcesado}");
                Console.WriteLine("PROCESO FINALIZADO CORRECTAMENTE");
                Console.WriteLine("==================================");
            }
            catch (OracleException ex)
            {
                Console.WriteLine();
                Console.WriteLine("Error de Oracle:");
                Console.WriteLine(ex.Message);
            }
            catch (Exception ex)
            {
                Console.WriteLine();
                Console.WriteLine("Error en el programa:");
                Console.WriteLine(ex.Message);
            }

            Console.WriteLine();
            Console.WriteLine("Presiona una tecla para salir.");
            Console.ReadKey();
        }
    }
}

5. Configurar la conexión
La cadena de conexión usada en el ejemplo es:
User Id=SYSTEM;Password=TU_CLAVE;Data Source=localhost:1521/orcl;
Ajusta sus valores según tu instalación:
- User Id: usuario de Oracle.
- Password: contraseña de ese usuario.
- Data Source: host, puerto y nombre del servicio Oracle.
Por ejemplo, si tu base utiliza otro servicio, reemplaza orcl por el nombre correcto. Si aparece ORA-12514,
verifica el nombre del servicio; si aparece ORA-01017, verifica el usuario y la contraseña.

8. Consultar los datos desde Oracle
Ver los registros
SELECT
    ID,
    LOTE_ID,
    VALOR,
    FECHA_REGISTRO
FROM NUMEROS_CONTADOS
ORDER BY ID;

Contar todos los registros de la tabla
SELECT COUNT(*) AS TOTAL_REGISTROS
FROM NUMEROS_CONTADOS;

Esta última consulta cuenta los registros de todas las ejecuciones. Cada vez que se ejecuta el programa se agrega un nuevo
lote de 50 números.
Contar los números de una ejecución concreta

El programa genera un LOTE_ID nuevo en cada ejecución. Para consultar el lote de una ejecución específica,
utiliza el valor de LOTE_ID mostrado en la tabla:
SELECT COUNT(*) AS TOTAL_LOTE
FROM NUMEROS_CONTADOS
WHERE LOTE_ID = 'REEMPLAZAR-POR-EL-LOTE-ID';

9. Solución de problemas
Problema	Qué revisar
ORA-01017	Usuario o contraseña incorrectos.
ORA-12154 o ORA-12514	Descriptor de conexión o nombre del servicio.
ORA-12541	Listener de Oracle detenido o puerto incorrecto.
ORA-00942	La tabla no existe en el esquema con el que te conectaste.
No se encuentra Oracle.ManagedDataAccess.Client	Instala el paquete NuGet en el proyecto correcto.
No conecta a localhost:1521/orcl	Comprueba el host, puerto, listener y servicio real de tu instalación.
